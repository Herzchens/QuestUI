# Contributors

QuestUI is maintained by [Herzchens](https://github.com/Herzchens).

## Project contributors

- [Herzchens](https://github.com/Herzchens) - Project maintainer; started QuestUI from the extracted Quest shortcut/status indicator seed, then independently built and maintains the standalone Dashboard, Quest cards, manual actions, diagnostics, notifications, updater, Orion integration, compatibility work, documentation, and releases.
- [nyxxbit](https://github.com/nyxxbit) - Contributed the settings-bar accessibility and tooltip fix in [pull request #3](https://github.com/Herzchens/QuestUI/pull/3), compatibility analysis, and maintenance guidance.

## Upstream credit

- [nicola02nb](https://github.com/nicola02nb) - Created the original Quest shortcut icon/status-dot UI in [completeDiscordQuest](https://github.com/nicola02nb/completeDiscordQuest), which provided the small UI seed from which QuestUI began. The later QuestUI Dashboard and feature set were developed independently.
- [Vencord contributors](https://github.com/Vendicated/Vencord/graphs/contributors) - Provide and maintain the plugin framework used by QuestUI.

Contributions of code, testing, compatibility research, documentation, and issue reports are appreciated.
