# Contributors

QuestUI is maintained by [Herzchens](https://github.com/Herzchens).

## Project contributors

- [Herzchens](https://github.com/Herzchens) — Project maintainer; extracted and refactored the Quest UI into a standalone read-only plugin and maintains compatibility, navigation, status handling, documentation, and releases.
- [nyxxbit](https://github.com/nyxxbit) — Contributed the settings-bar accessibility and tooltip fix in [pull request #3](https://github.com/Herzchens/QuestUI/pull/3), compatibility analysis, and maintenance guidance.

## Upstream credit

- [nicola02nb](https://github.com/nicola02nb) — Created the original Quest UI implementation in [completeDiscordQuest](https://github.com/nicola02nb/completeDiscordQuest), from which QuestUI was independently extracted and refactored.
- [Vencord contributors](https://github.com/Vendicated/Vencord/graphs/contributors) — Provide and maintain the plugin framework used by QuestUI.

Contributions of code, testing, compatibility research, documentation, and issue reports are appreciated.
